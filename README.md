# itsmetanishk3-sys.github.io

Personal portfolio website of **Tanishk Srivastava** — Electrical & Computer Engineering undergrad at ABES Engineering College, Ghaziabad.

🌐 **Live Site**: [itsmetanishk3-sys.github.io](https://itsmetanishk3-sys.github.io)

## ✨ Features

- 🌙/☀️ Dark/Light theme toggle with persistent preference
- 🎆 Interactive particle system with mouse repulsion
- ⌨️ Typing animation with multiple role phrases
- 🃏 3D tilt card effects on hover
- 📊 Animated skill progress bars
- 🔢 Animated counters
- 🗂️ Project filter by category
- 📱 Fully responsive & mobile-friendly
- 🖱️ Custom cursor (desktop)
- 🚀 Scroll-reveal animations
- ✉️ Contact form (Formspree)

## 🛠️ Stack

- Pure **HTML5**, **CSS3**, **Vanilla JavaScript**
- Fonts: Orbitron, Inter, JetBrains Mono (Google Fonts)
- Icons: Font Awesome 6
- Hosted on **GitHub Pages**

## 📂 Structure

```
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── main.js
│   └── particles.js
└── assets/
    ├── favicon.svg
    └── resume.pdf     ← Add your resume here
```

## 🚀 Setup

1. Clone this repo
2. Update your personal info in `index.html`
3. Add your `assets/resume.pdf`
4. Set up [Formspree](https://formspree.io) and replace `YOUR_FORMSPREE_ID` in `js/main.js`
5. Push to GitHub — Pages auto-deploys!
